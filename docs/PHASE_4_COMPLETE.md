## Что сделано

### 4.1 Маркетплейс скиллов — полный цикл

**Публикация:**
- `POST /api/v1/marketplace/skills/publish/` — опубликовать новый скилл
- Поля: name, description, category, price, tags, requirements, config_schema

**Покупка + установка:**
- `POST /api/v1/skills/skills/{id}/install/` — установить скилл на бота
- Автоматическая оплата IAM-coin + revenue split (60/30/10)
- Проверка баланса → списание → запись установки

**Поиск и фильтрация:**
- `GET /api/v1/marketplace/skills/search/` — поиск с фильтрами
- Параметры: q, category, min_price, max_price, sort_by
- Сортировка: popularity, rating, price_low, price_high, newest

**Отзывы:**
- `POST /api/v1/marketplace/skills/{id}/review/` — оценка 1-5 + комментарий
- Автоматический пересчёт среднего рейтинга

### 4.2 Торговля ботами

**Выставление на продажу:**
- `POST /api/v1/marketplace/bots/{id}/list/` — выставить бота за X IAM-coins

**Покупка:**
- `POST /api/v1/marketplace/bots/{id}/buy/` — купить бота
- Передача владельца + оплата + запись транзакции

### 4.3 IAM Coin Info

- `GET /api/v1/iam-coin/info/` — информация о контракте (адрес, supply, decimals)
- `GET /api/v1/iam-coin/balance/{address}` — баланс любого адреса через TonCenter

### 4.4 Управление ботами — полный набор callback'ов

| Callback | Действие |
|----------|----------|
| `manage_bot_{id}` | Панель управления |
| `restart_bot_{id}` | Перезапуск контейнера |
| `stop_bot_{id}` | Остановка (sleep mode) |
| `start_bot_{id}` | Запуск после остановки |
| `delete_bot_{id}` | Удаление с подтверждением |
| `confirm_delete_bot_{id}` | Подтверждение удаления |
| `logs_bot_{id}` | Логи контейнера |
| `view_bot_{id}` | Просмотр бота в маркетплейсе |
| `buy_bot_{id}` | Покупка бота |
| `confirm_buy_bot_{id}` | Подтверждение покупки |

### 4.5 Seed-данные
