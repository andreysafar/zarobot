# Ручное тестирование хелпера

Проверка от быстрой к полной. Шаг 0 не требует ни секретов, ни сети.

---

## Шаг 0. Локальный прогон без Telegram (2 минуты)

```bash
python scripts/demo_flow.py
```

Показывает весь флоу: Дервалер выгружает архив → админ ведёт FAQ →
хелпер отвечает на вопросы → живое дозаписывание.

**Что проверить:**
- Архив: сохранено 6 сообщений, курсор 6
- FAQ: черновики создаются, после `/faq_publish` появляются в `/faq`
- Ответы: «как деплоить?» и «где пароль?» отвечают из FAQ,
  «какой адрес у стенда?» — цитатой из архива
- Живое обновление: после добавления сообщения курсор 6 → 7 и
  «какой домен купили?» находит новое сообщение

## Шаг 1. Подготовка (один раз)

### 1.1 Узнать `api_id` / `api_hash`
https://my.telegram.org → API development tools → создать приложение.

### 1.2 Создать бота-хелпера
[@BotFather](https://t.me/BotFather) → `/newbot` → токен.
Обязательно: `/setprivacy` → **Disable** — иначе бот не увидит сообщения группы.

### 1.3 Узнать id чата
Добавить бота и аккаунт-администратора в один чат. Узнать id:

```bash
# временно: переслать любое сообщение из чата боту @userinfobot
# или @RawDataBot — он покажет chat.id
```

Формат: `-1001234567890`.

### 1.4 Заполнить `.env`

```bash
cp .env.example .env
```

Обязательные:

```env
TELEGRAM_API_ID=...
TELEGRAM_API_HASH=...
HELPER_BOT_TOKEN=...        # токен хелпера от BotFather
HELPER_CHAT_ID=-100...      # id чата
OPENROUTER_API_KEY=...      # ключ OpenRouter
OWNER_ID=...                # ваш Telegram user id
```

## Шаг 2. Сессия администратора (один раз)

Дервалер входит **вашим аккаунтом**, поэтому сессию создаёте вы вручную.

```bash
pip install -r services/dervaler/requirements.txt
python -m services.dervaler.bootstrap_session
```

Скрипт спросит телефон, код из Telegram и, если включён, пароль 2FA.
Сессия сохранится в `data/dervaler/session`.

> ⚠️ Файл сессии = пароль от аккаунта. Он в `.gitignore`, но не пересылайте
> его и не коммитьте.

Проверка: в логе `Вход выполнен: <ваш username>`.

## Шаг 3. Выгрузка архива

Сначала ограничьте объём, чтобы убедиться, что всё работает:

```bash
export DATA_DIR=$PWD/data
export HELPER_CHAT_ID=-1001234567890
export DERVALER_MAX_MESSAGES=200
python -m services.dervaler.worker
```

**Ожидаемый результат:**
```
Начинаю инжест чата -100... (курсор=0)
Пачка чата -100...: прочитано 200, сохранено N, курсор=...
Инжест чата -100... завершён. Сохранено N. Курсор=...
```

**Проверка возобновления** (главное): запустите ещё раз — курсор должен
быть **не** 0, а «Сохранено» — заметно меньше или 0. Сообщения не
должны удваиваться:

```bash
python -c "
import sys; sys.path.insert(0,'services')
from dervaler.store import Store
s = Store('data/dervaler/archive.sqlite3')
print('сообщений:', s.message_count($HELPER_CHAT_ID))
print('курсор   :', s.get_checkpoint($HELPER_CHAT_ID))
"
```

Запустите дважды — число сообщений не должно расти.

**Полная выгрузка** (снять лимит):
```bash
unset DERVALER_MAX_MESSAGES
python -m services.dervaler.worker
```
На большом чате это займёт время — Telethon ждёт 1с между пачками,
`FloodWaitError` обрабатывается автоматически.

## Шаг 4. Живой чат

### 4.1 Поднять хелпера

```bash
docker compose up -d --build redis helper-bot dervaler
./scripts/install_helper_skill.sh helper_bot_data
docker compose restart helper-bot
docker compose logs -f helper-bot
```

### 4.2 Проверить: хелпер молчит на болтовню

Написать в группу: `привет всем, как дела?`

**Ожидаемо:** ответа нет. В логах:
`Ignoring chatter in chat ...` или
`Question in chat ... left unanswered — no skill content`

### 4.3 Проверить: ответ по архиву

Написать: `@ваш_бот как деплоить?` (или фразу-активацию «Ия, ...»)

**Ожидаемо:** ответ из FAQ или цитата из истории.

### 4.4 Проверить: команды

| Команда | Ожидаемо |
|---|---|
| `/faq` | список опубликованных записей |
| `/ask как деплоить?` | ответ из базы |
| `/ingest_status` | счётчики архива и курсор |
| `/faq_add Вопрос? \| Ответ` | ⛔ обычному участнику, ✅ админу |
| `/faq_publish <id>` | ✅ админу, запись появляется в `/faq` |

### 4.5 Проверить: права администратора

Под **обычным** участником: `/faq_add Тест | Тест`
→ `⛔ Эта команда только для администраторов чата.`

Под **админом чата** (или `OWNER_ID`): та же команда создаёт черновик.

> Это единственное место, не покрытое автотестами: `GetParticipantRequest`
> требует живой сети. Проверьте обязательно.

### 4.6 Проверить: живое обновление

1. Написать в группу сообщение с уникальным фактом:
   `Купили домен example.com`
2. Подождать ~10 секунд (Дервалер дозаписывает по `NewMessage`)
3. Спросить: `@ваш_бот какой домен купили?`

**Ожидаемо:** ответ содержит `example.com`.

## Шаг 5. Что делать, если не работает

| Симптом | Причина | Решение |
|---|---|---|
| Бот не видит сообщения группы | privacy mode | BotFather → `/setprivacy` → Disable |
| Дервалер: «Нет сессии» | не выполнен шаг 2 | `bootstrap_session` |
| Дервалер: «Чат не в белом списке» | неверный `HELPER_CHAT_ID` | проверить id |
| Хелпер молчит на всё | скилл не установлен | `./scripts/install_helper_skill.sh` |
| Хелпер отвечает «не нашёл» | пустая база | сначала выгрузить архив (шаг 3) |
| Отвечает на болтовню | — | проверить логи: должен быть `Ignoring chatter` |
| `/faq_add` — ⛔ для админа | не определяется админ | проверить `OWNER_ID` |

Логи:
```bash
docker compose logs -f helper-bot dervaler
```
