# Zero Bot Platform — Status Report

**Дата:** 2026-09-09
**Блокчейн:** TON (не Solana — старые упоминания в доках устарели)

Документ описывает **проверенное** состояние платформы. Всё, что помечено
как готовое, подтверждено тестами или сквозным прогоном; всё остальное явно
названо заглушкой или неподключённым.

## Архитектура

```
                    ┌──────────────┐
                    │   Core API   │  FastAPI + SQLite
                    │  (backend)   │  токен обязателен, порт только localhost
                    └──────┬───────┘
                           │
      ┌────────────┬───────┴────────┬──────────────┐
      │            │                │              │
┌─────┴─────┐ ┌────┴─────┐ ┌────────┴──────┐ ┌─────┴─────┐
│ IA-Mother │ │ Скрепка  │ │  Helper-бот   │ │ Дервалер  │
│  (мастер) │ │ (админ)  │ │   (группа)    │ │ (архив)   │
└─────┬─────┘ └────┬─────┘ └───────────────┘ └───────────┘
      │            │
      │      Docker socket → мониторинг и рестарт ботов
      │
      └──→ spawn zero_bot_<id> (по контейнеру на бота)

              Redis · Langflow
```

Сервисы в `docker-compose.yml`: `core-api`, `ia-mother`, `skrepka`,
`helper-bot`, `dervaler`, `redis`, `langflow`.

## Экономика: две валюты, два хранилища

Решение принято осознанно и закреплено тестами.

| | Звёзды | IAM |
|---|---|---|
| Хранилище | SQLite, таблица `balances` | JSON-реестр `IAMCoinService` |
| Роль | оплата сервисов бота его владельцу | AI-токены, навыки, персоны |
| Будущее | остаётся в платформе | уезжает в минт NFT / ончейн |

Колонки `ia_coins` в SQLite **больше нет**: две копии одного баланса
приводили к тому, что монеты списывались в одном месте, а начислялись
в другом.

Курс задаёт сервер: 1 ⭐ = 0.01 IAM, 1 IAM = 100 ⭐. Обмен туда-обратно
нейтрален — обратный обмен сжигает монеты, а не оставляет их в обороте.

Доли с покупки: 60% автору, 30% платформе, 10% Telegram. Деньги идут
**от покупателя**, общая масса монет не меняется.

### Чего в экономике ещё нет

Звёзды сейчас невозможно заработать: интеграции Telegram Payments нет,
а бот-инстанс о деньгах не знает вообще. Пока звёзды попадают в систему
только через админский эндпоинт. Это следующий крупный кусок работы.

## Безопасность

| Что | Как сейчас |
|---|---|
| Core API | Токен `CORE_API_TOKEN` на всех эндпоинтах кроме `/health`; без токена сервис отвечает 503 |
| Порты | Core API и Redis слушают только `127.0.0.1` |
| Redis | Пароль через `REDIS_PASSWORD` |
| Приватные ключи TON | Шифруются Fernet (`WALLET_ENCRYPTION_KEY`); без ключа операции отклоняются |
| Курс обмена | Считает сервер; `to_amount` и `rate` из запроса игнорируются |
| Создание ботов | Закрыто по умолчанию: `OWNER_ID` + `ALLOWED_CREATOR_IDS`, публичный режим — явный флаг |
| Права на боты | Выставить на продажу и ставить навыки может только владелец |

Проверка аутентификации сделана middleware, а не зависимостью на роут:
новый эндпоинт защищён по умолчанию, а не когда про него вспомнят.

## Переменные окружения

Обязательные:

```bash
TELEGRAM_API_ID=          # Telegram API (my.telegram.org)
TELEGRAM_API_HASH=
IA_MOTHER_BOT_TOKEN=      # токен мастер-бота от BotFather
CORE_API_TOKEN=           # openssl rand -hex 32; без него Core API не стартует
```

Рекомендуемые:

```bash
WALLET_ENCRYPTION_KEY=    # Fernet-ключ; без него операции с TON-кошельками отклоняются
REDIS_PASSWORD=           # пусто = без пароля (только локальная разработка)
OWNER_ID=                 # кому разрешено создавать ботов
ALLOWED_CREATOR_IDS=      # ещё id через запятую
SKREPKA_BOT_TOKEN=        # чат отладки: отдельный бот
ADMIN_CHAT_ID=            # куда Скрепка шлёт баги и инциденты
OPENROUTER_API_KEY=       # LLM
```

Полный список — в `.env.example`. Секреты в git не попадают:
`.env`, `*.session`, `data/` в `.gitignore`.

## Запуск

```bash
cp .env.example .env
# заполнить как минимум TELEGRAM_API_ID/HASH, IA_MOTHER_BOT_TOKEN, CORE_API_TOKEN
docker compose up -d --build
```

Сервисы: Core API — `http://127.0.0.1:8000`, Langflow — `http://localhost:7860`.

Проверка без Docker и Telegram:

```bash
pytest                      # весь набор
python scripts/demo_flow.py # сквозной прогон helper-бота
```
